# Localization

- Languages: English (default), Urdu, optional Pashto.
- All UI text in resource/localisation files; no hardcoded strings.
- Currency: `Rs. 1,250` format via one shared formatter.
- Dates: DD/MM/YYYY, 12-hour time, timezone Asia/Karachi (PKT, UTC+5).
- Phone: store E.164 (`+923XXXXXXXXX`), display local format.
- Test layouts in RTL mode.
