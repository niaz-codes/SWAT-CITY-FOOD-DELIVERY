# Swat City Food Delivery

Food delivery system for Swat, Khyber Pakhtunkhwa, Pakistan.

## Apps / Parts

| Part             | Purpose                                       |
| ---------------- | --------------------------------------------- |
| Customer app     | Browse restaurants, order, pay, track         |
| Rider app        | Accept deliveries, update status, collect COD |
| Restaurant panel | Manage menu, accept/reject orders             |
| Admin panel      | Users, restaurants, orders, payouts, reports  |
| Backend API      | Business logic, auth, payments, notifications |

## Tech stack

> Fill in / confirm: mobile (Flutter or Android Java/XML), backend (Node/Laravel/Firebase etc.), database, hosting.

## Quick start

1. Clone repo
2. Copy `.env.example` to `.env` and fill values (never commit `.env`)
3. Install dependencies
4. Run backend, then app
