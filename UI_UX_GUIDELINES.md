# UI/UX Guidelines

- Design for low-end Android phones and slow networks (3G/4G in Swat).
- Image caching, lazy lists, small APK/app size.
- Large touch targets (min 48dp), readable fonts.
- Consistent components: restaurant card, menu item, status chip, price text.
- Always show: loading, empty, and error states.
- Support RTL (Urdu) layout and Pashto where needed.
- Checkout in max 3 steps; show total early.
- Order tracking: simple timeline with status colours.
- Accessibility: contrast, content descriptions.
