# Features

## Customer

- Phone OTP signup/login, saved addresses
- Browse by area, cuisine, rating; search
- Cart, coupons, order notes
- COD / JazzCash / Easypaisa checkout
- Live order tracking, order history, reorder
- Ratings and reviews, support chat

## Restaurant

- Menu and price management, item availability toggle
- Accept/reject orders, preparation time
- Opening hours, daily sales report

## Rider

- Online/offline toggle, accept delivery
- Navigation to restaurant and customer
- Earnings and COD cash summary

## Admin

- Manage users, restaurants, riders, zones
- Orders monitor, refunds, payouts
- Coupons, banners, reports, audit log
