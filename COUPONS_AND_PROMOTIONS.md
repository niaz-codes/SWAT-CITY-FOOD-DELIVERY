# Coupons & Promotions

## Types

- Percentage off (with max cap)
- Flat amount off
- Free delivery
- First-order discount

## Validation (server-side)

- Active dates, usage limit total and per user
- Minimum order value
- Eligible restaurants/zones
- Cannot stack unless explicitly allowed

## Abuse prevention

- One first-order coupon per phone number and device
- Rate-limit coupon attempts
- Log every redemption
